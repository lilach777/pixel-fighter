## Derived / generated animations (no dedicated art on the sheets)

| Animation | How it is produced |
|---|---|
| walkBack | derived: walk cycle played in reverse |
| backdash | derived: walk frames, no dedicated back-dash art |
| jump | derived: no jump art on sheets; crouch take-off + mid-stride run frames in the air |
| block | derived: guard frame + engine-drawn shield flash |
| crouchBlock | derived: crouch frame + engine-drawn shield flash |
| hurt | derived: recoil crouch frame + engine hit flash/shake |
| airPunch | derived: punch frame used while airborne |
| hit flash | Engine draws a white tint over the current frame (original effect). |
| projectiles | Procedural pixel fireballs / crescent / spark spray drawn by the renderer (original effects); the sheets' fire-arc punch frames play as the launch animation. |
| hit sparks, block shield, dust, super rays | Procedural original effects (client/src/game/rendering/effects.ts). |

Mirroring: every sheet faces right; fighters facing left are drawn mirrored (text on clothing therefore appears mirrored for the right-side player).
